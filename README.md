# منصة التعليم العربية (Arabic Education Platform)

منصة تعليمية عربية متكاملة تتيح للمعلمين إنشاء ومشاركة الدورات التعليمية، وللطلاب الاستفادة من هذه الدورات. المنصة تدعم اللغة العربية بالكامل وتتضمن نظام إدارة متكامل.

## نظرة عامة على المشروع

### المميزات الرئيسية

- **نظام متعدد المستخدمين**: مدير، معلم، طالب
- **نظام مصادقة متكامل**: تسجيل الدخول، التسجيل، والتحقق
- **نظام للموافقة على الحسابات**: مراجعة وإدارة طلبات التسجيل من قبل المدير
- **إدارة الدورات**: إنشاء، تعديل، وحذف الدورات من قبل المعلمين
- **واجهة مستخدم عربية سهلة الاستخدام**: تصميم يدعم RTL والخطوط العربية
- **وضع الألوان الداكنة**: إمكانية التبديل بين الوضع الفاتح والداكن
- **تصميم متجاوب**: تعمل المنصة بشكل مثالي على جميع أحجام الشاشات

### التقنيات المستخدمة

#### الواجهة الأمامية (Frontend)
- React.js
- React Router
- Tailwind CSS
- Framer Motion
- Context API (للمصادقة والوضع الداكن)
- Axios

#### الواجهة الخلفية (Backend)
- Node.js
- Express.js
- JSON Web Tokens (JWT)
- bcrypt.js (لتشفير كلمات المرور)

## نظام الأدوار والصلاحيات

### مدير النظام (Admin)
- يستطيع الموافقة أو رفض حسابات المعلمين والطلاب
- لديه إمكانية الوصول إلى جميع الدورات والمستخدمين
- يمكنه عرض إحصائيات النظام والمستخدمين

### المعلم (Teacher)
- إنشاء وتعديل وحذف الدورات الخاصة به
- عرض الطلاب المسجلين في دوراته
- إدارة المحتوى التعليمي للدورات

### الطالب (Student)
- تصفح الدورات المتاحة
- التسجيل في الدورات
- متابعة تقدم التعلم في الدورات المسجل بها

## نظام المصادقة

### التسجيل
- نماذج منفصلة لتسجيل المعلمين والطلاب
- التحقق من صحة المدخلات
- تشفير كلمات المرور

### تسجيل الدخول
- مصادقة قائمة على JWT
- توجيه المستخدم إلى لوحة التحكم المناسبة حسب دوره

### نظام الموافقة
- حسابات المعلمين والطلاب تبقى معلقة حتى يتم الموافقة عليها من قبل المدير
- عرض رسالة "حسابك قيد التفعيل" للمستخدمين الذين لم تتم الموافقة عليهم بعد

## نظام إدارة الدورات

### إنشاء الدورات
- نموذج لإنشاء دورة جديدة (للمعلمين فقط)
- تحديد العنوان، الوصف، التصنيف، المستوى، وأهداف الدورة

### إدارة المحتوى
- إضافة وتعديل وحذف المحتوى التعليمي للدورة
- دعم أنواع مختلفة من المحتوى (نص، روابط، إلخ)

### تسجيل الطلاب
- نظام تسجيل الطلاب في الدورات
- عرض قائمة بالطلاب المسجلين (للمعلمين)

## تشغيل المشروع محلياً

### المتطلبات الأساسية
- Node.js (الإصدار 14 أو أعلى)
- npm أو yarn

### خطوات التثبيت والتشغيل

1. **نسخ المشروع**
   ```bash
   git clone https://github.com/yourusername/arabic-education-platform.git
   cd arabic-education-platform
   ```

2. **تثبيت التبعيات**
   ```bash
   # تثبيت تبعيات الواجهة الخلفية
   cd server
   npm install
   
   # تثبيت تبعيات الواجهة الأمامية
   cd ../client
   npm install
   ```

3. **تشغيل الواجهة الخلفية**
   ```bash
   cd ../server
   npm run dev
   ```

4. **تشغيل الواجهة الأمامية**
   ```bash
   cd ../client
   npm start
   ```

5. **الوصول إلى المنصة**
   افتح المتصفح وانتقل إلى `http://localhost:3000`
